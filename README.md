# SillyTavern 文生图 (st-chatu8)

**作者:** 从前跟你一样
**版本:** 1.0.0

这是一个为 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 设计的第三方扩展，它将强大的文生图功能无缝集成到您的聊天体验中。通过简单的标记，您可以在对话中直接调用 Stable Diffusion、NovelAI 或 ComfyUI，将文字描述变为生动的图像。

## ✨ 功能

- **多后端支持**:
    - **Stable Diffusion**: 通过 A1111/Forge WebUI API 连接。
    - **NovelAI**: 支持官方及第三方 NovelAI API。
    - **ComfyUI**: 通过导入工作流 (Workflow) 实现高度自定义的图像生成。
- **简单易用的触发方式**: 在聊天中用自定义的开始和结束标记（如 `[prompt]`）包裹提示词，即可自动生成图片。
- **高度可配置**:
    - **全局设置**: 在多种后端之间轻松切换，并配置全局触发标记。
    - **精细化参数**: 为每个后端（SD, NovelAI, ComfyUI）分别设置模型、采样器、尺寸、步数、CFG 等详细参数。
    - **高级功能**: 支持 SD 的高清修复 (Hires. fix)、ADetailer；支持 NovelAI 的氛围参考 (Vibe Transfer)、角色参考 (Character Reference)；支持 ComfyUI 的 LORA 和自定义工作流。
- **提示词管理**:
    - **固定提示词**: 为每个后端设置固定的正面和负面提示词。
    - **提示词预设**: 保存和加载多套提示词配置，方便在不同风格间切换。
    - **动态替换**: 设置规则，自动将聊天中的特定词语替换为更适合绘画的提示词。
- **用户体验优化**:
    - **图片缓存**: 内置图片缓存系统，可预览、管理和下载生成的图片，并设置缓存有效期。
    - **便捷操作**: 支持长按图片修改提示词、双击图片重新生成。
    - **界面集成**: 在主界面添加设置入口，并提供可自定义的悬浮球按钮。
    - **自动更新**: 启动时自动检查并提示插件更新。

## 🚀 安装

1.  在 SillyTavern 的扩展菜单中，从以下 URL 安装插件：
    ```
    https://github.com/damoshen123/st-chatu8
    ```
2.  重启 SillyTavern。
3.  在扩展菜单中启用 "st-chatu8"。

## 📖 使用方法

核心使用流程非常简单：

### 1. 打开设置面板

点击侧边栏的 **“打开文生图设置”** 按钮，或通过悬浮球进入插件的设置面板。

### 2. 配置后端

-   在 **“主要设置”** 标签页中，选择您希望使用的 **模式** (SD / NovelAI / ComfyUI)。
-   切换到对应后端的标签页 (例如 "SD")，填入您的 API 地址 (如 `http://127.0.0.1:7860`)，并点击 **“测试连接”** 确保插件可以正常通信。
-   根据您的需求，配置模型、采样器、默认尺寸等参数。

### 3. 在聊天中生成图片

在任意聊天消息中，使用您在 **“主要设置” -> “标记”** 中定义的 **开始标记** 和 **结束标记** (默认为 `[` 和 `]`) 来包裹您的绘图提示词。

**示例:**

```
[1girl, solo, beautiful detailed eyes, looking at viewer]
```

插件会自动检测到这段内容，调用您选择的后端，并将生成的图片显示在聊天界面中。

## ⚙️ 设置选项

插件提供了丰富的设置选项，分布在不同的标签页中：

### 主要设置

-   **启用插件**: 插件的总开关。
-   **模式**: 选择默认使用的文生图后端 (SD, NovelAI, ComfyUI)。
-   **标记**: 自定义用于触发图片生成的开始和结束符号。
-   **缓存管理**: 设置图片缓存的有效期，或一键清除所有缓存。

### SD / NovelAI / ComfyUI 标签页

每个后端都有独立的配置页面，通常包括：

-   **API 地址**: 连接后端服务的 URL。
-   **固定提示词**: 设置全局的正面和负面提示词，支持预设管理。
-   **提示词替换**: 定义规则，将特定文本替换为其他内容 (例如 `马` -> `horse`)。
-   **质量预设**: 快速启用/禁用通用的高质量或低质量提示词。
-   **生成参数**:
    -   模型 (Model), VAE, 采样器 (Sampler), 调度器 (Scheduler)
    -   图片宽度 (Width) 和高度 (Height)
    -   采样步数 (Steps), CFG 缩放
    -   种子 (Seed)
-   **高级选项**:
    -   **SD**: 高清修复、面部修复 (Restore Faces)、ADetailer。
    -   **NovelAI**: SMEA, Vibe Transfer, Character Reference 等。
    -   **ComfyUI**: 工作流 (Workflow) 管理，允许您粘贴从 ComfyUI 导出的 API JSON。

### 其他标签页

-   **主题设置**: 自定义设置面板的颜色主题。
-   **悬浮球**: 配置悬浮球的开关、样式和大小。
-   **图片缓存**: 查看和管理所有已生成的图片。
-   **关于**: 查看插件信息、检查更新以及获取帮助。

## ComfyUI 生图链路优化

智绘姬的 ComfyUI 链路现在按“插件可控编译”执行：LLM 只负责画面意图，插件负责角色锁定、世界风格、服装状态、冲突清洗与最终提示词组装。

### 最终调试面板

开启 ComfyUI 调试面板后，每次生成会记录：

-   `角色身份信息`、`服装`、`服装状态`、`当前画面` 四个流程变量。
-   总提示词、负面提示词、参考图路径。
-   工作流警告/报错摘要；需要排错时可展开查看完整工作流细节。
-   自动服装预设生成状态与失败原因（仅在触发时显示）。

调试面板用于确认工作流变量拿到的值、参考图是否真的传入，以及正负面提示词是否接入 KSampler。

### 提示词编译器

ComfyUI 正面提示词固定按以下顺序编译：

1. 质量词。
2. 世界风格。
3. 单人控制。
4. 角色主体锁定。
5. 表情动作。
6. 服装基础。
7. 服装状态。
8. 场景环境。
9. 镜头构图。

单参考图工作流默认注入 `solo, single subject, one person only`。角色名、参考图、发色、瞳色、脸型、体型等固定特征由插件强制注入；LLM 输出中的冲突发色、瞳色、体型等低优先级词会被清洗。

服装按状态机处理：默认保持上一套服装；只有正文明确换衣、穿上某套衣服时才切换服装预设；湿了、破损、凌乱、沾血等描述只叠加为当前服装状态。

### ComfyUI 工作流变量

旧版“工作流可视化”弹窗的文本类输入旁边有 `</>` 占位符按钮。点击后会使用旧实现的原生下拉菜单插入变量，也可以手动写入工作流 JSON 的字符串字段中：

-   `%角色身份信息%` / `%character_identity%`: 角色固定身份与外观锁定信息，不包含服装、动作或场景。
-   `%服装%` / `%outfit%`: 当前角色服装预设的基础英文绘图 tags。
-   `%服装状态%` / `%outfit_state%`: 本次服装状态，例如 wet outfit、torn fabric、disheveled outfit。
-   `%当前画面%` / `%current_frame%`: 本次画面的动作、表情、互动、地点、环境、光影、视角与构图。

这些变量只作用于 ComfyUI 工作流字符串字段；空值会替换为空字符串，不会把 `%outfit_state%` 这类占位符原样留在最终工作流里。原有总提示词变量（如 `%prompt%` / `%positive%`）仍然可用，适合旧工作流继续使用。

ComfyUI 设置页提供“剧情换装自动生成服装预设”开关，默认关闭。开启后，正文出现换装但没有命中现有服装预设时，插件会为当前主角色异步请求 LLM，把新服装整理成英文基础 tags 并保存为角色专属服装预设；湿透、破损、凌乱等只进入当次 `%outfit_state%`。如果 LLM 失败，本次仍可通过 `%current_frame%` 表达换装，但不会保存新预设，并会在调试面板显示失败原因。

### 角色首参考图 LLM 系统提示词

ComfyUI 设置页的“角色首参考图生成工作流”区域提供“角色首参考图 LLM 系统提示词”。它只影响角色首张参考图的“生成图片提示词”按钮：插件会把这里的内容作为 system message 注入该次 LLM 请求，让 LLM 按你的规则输出更适合生图的英文提示词。留空时不注入额外系统提示词。

### 世界风格预设

ComfyUI 设置页新增“世界风格锁定”预设管理，数据保存在 `comfyWorldStylePresets`，当前选择保存在 `selectedComfyWorldStylePresetId`。旧的 `comfyWorldStylePreset` 会继续兼容。

世界风格字段包括：

-   `name`: 预设名称。
-   `quality`: 质量词。
-   `positive`: 固定正面风格词，包含画风、光影、镜头、色彩、材质、年代、环境母题。
-   `negative`: 固定负面约束。
-   `source_summary`: 来源摘要。
-   `warnings`: 生成时的警告。

世界风格不得混入角色身份、发色瞳色、体型、服装或当前剧情动作。

### 世界书生成世界风格

LLM 请求类型配置新增“世界风格生成”。点击 ComfyUI 世界风格面板的“世界书生成”，或 LLM 配置里的对应按钮后，可输入生成要求。插件会读取当前聊天已触发或启用的世界书上下文，请求 LLM 返回严格 JSON，并自动填入、保存为世界风格预设。

如果 LLM 请求失败，插件会使用当前世界书内容生成一个本地兜底预设，并把失败原因写入 `warnings`，便于继续排查。

### ComfyUI 工作流校准

生成前会检查最终工作流：

-   是否存在 KSampler。
-   KSampler 的 positive / negative 是否连接到 CLIPTextEncode。
-   `%comfyuicankaotupian%` 替换后的参考图路径是否出现在最终工作流。
-   有参考图时是否检测到 IPAdapter 节点。
-   即使负面节点写死文本，也会合并插件编译后的最终负面词。
-   即使 KSampler 节点写死 seed，也会同步为本次运行的 seed，避免工作流固定值盖掉随机种子。
-   有参考图且 `IPAdapter` 运行参数过弱时，会把 `weight` 保守提升到至少 `0.55`、`end_at` 提升到至少 `0.75`，并在调试面板记录具体节点。

如果参考图路径不在最终工作流，或 IPAdapter 节点缺失，调试面板会直接显示警告。固定 seed 只建议用于复现问题，正常生成应允许 seed 变化。

### Klein Prompt 优化 LLM

`image###...###` 到 Klein 工作流的链路新增可选 Prompt 优化层，默认关闭。

开启后，插件会在发送 ComfyUI 前先调用一个独立 LLM，把原始剧情描述改写成更适合 FLUX Klein 的自然语言英文提示词。推荐模式是“原文 + 优化补充”：原始 `image###` 内容仍会保留，优化结果只作为补充，避免 LLM 过度删改剧情。

ComfyUI 设置页可配置：

-   是否启用 Klein Prompt 优化 LLM。
-   输出模式：原文 + 优化补充、只用原文、只用优化结果。
-   独立请求类型，默认 `klein_prompt_optimize`，可配合单独的 API / Profile 使用。
-   是否启用失败回退原文。
-   是否把角色管理中的手写视觉特征交给优化 LLM。
-   是否读取已有视觉缓存特征，以及视觉缓存只补缺失信息还是参与补充。
-   优化 LLM 的系统指令。

角色视觉特征优先使用角色管理里手写的 `comfyIdentityPrompt` / `identityPrompt`。视觉模型能力设计为可选项；当前链路不会每次生图都强制跑视觉模型，只会在开启后读取已有视觉缓存字段。

调试面板会显示优化器状态、原因、原始提示词、优化补充提示词和最终发送给 Klein 的提示词，方便判断本次到底是原文直通、优化成功，还是失败回退。
